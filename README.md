# Dotfiles

Dotfiles for my setup.

## System info

- **OS** : [Arch Linux](https://archlinux.org)
- **WM** : [Hyprland](https://hypr.land)
- **Compositor** : [Wayland](https://wayland.freedesktop.org)
- **Terminal** : [kitty](https://github.com/kovidgoyal/kitty)
- **Shell** : Bash with [Starship](https://starship.rs) prompt

## Installation guide

> For the installation you will need some dependencies, something may be installed and can break your current setup. Do it at your own risk  
> This setup should be installed in a fresh Arch installation.

Simply run *install.sh* and check when asked for the superuser password.
